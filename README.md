# Harve Versionamento

Repositório de estudo criado durante uma etapa inicial de aprendizagem em desenvolvimento web e controle de versão.

## Objetivo

Praticar conceitos básicos de:

- HTML;
- CSS;
- JavaScript;
- Git;
- GitHub e versionamento de código.

## Estado do projeto

Este repositório representa um exercício inicial e foi mantido como **registro da evolução no aprendizado**. Ele não corresponde aos projetos atuais utilizados como principal demonstração de portfólio.

Para projetos mais recentes, consulte os demais repositórios do perfil.
